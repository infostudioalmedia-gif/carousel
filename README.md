# سيستم كاروسيل رؤية

تشغيل محلي: `START.bat` (أو `python app\server.py`) ثم http://localhost:8765

## مسار العمل
1. **الإدخال:** صوت أو فيديو أو رابط أو مسار ملف + **اختيار نمط الشهر** (نوفمبر / أكتوبر / ما يتضاف بعدهم)
2. **تحليل:** تفريغ (Scribe) ← لقطات للفيديو ← **✋ اقتراح عدد الشرايح** من محتوى الكلام (نقاط متسلسلة أو طول الكلام؛ 5–10 بالغلاف وصفحة الـCTA) وتأكيدك له ← storyboard ← **تصميم مبدئي** بأماكن صور فاضية (INSERT n).
3. **الانسرتات المطلوبة (توقف):** برومبت لكل صورة مطلوبة بنمط رؤية المعرّف للصور بالذكاء الاصطناعي، حسب النمط المختار. تجهّز الصور: رفع / لقطة من الفيديو / مسار فولدر على الجهاز أو الدرايف.
4. **«كمّل التصميم»:** يركّب الصور ويعرض التصاميم النهائية (2160×2160 + PDF + ZIP + كابشن).
5. **باقي المراحل:** تعديل النص أو استبدال صورة ثم إعادة التصميم، أو تغيير النمط وإعادة الرندر.

## ثوابت التصميم (كل الأنماط)
- **الغلاف:** صورة بملء الشريحة بدون فريم، تتلاشى لكحلي الخلفية، والعناوين (118 ← 73 ← 45) والمستطيل فوقها على لون موحّد.
- **صفحة CTA ثابتة في آخر الكاروسيل**، من محتوى الملف (`cta` في الـ storyboard: hd + p + button)، وفيها **باركود رؤية** (`qr.svg`) يتركّب تلقائيًا.

## نمط رؤية للصور (ثابت في كل البرومبتات)
تصوير صناعي وثائقي واقعي داخل مصنع ألبان حديث: استانلس 316L ولحامات صحية وجدران بلاط أبيض، إضاءة جانبية قاسية من اليسار + ملء محايد، **ألوان طبيعية بدون تلوين أزرق/تيل**، عدسة 50mm f/4، تكوين نظيف، **بدون أي نص أو أرقام أو لوجو أو وجوه معروفة**. كل نمط يضيف قاعدة التكوين الخاصة به (أكتوبر: الموضوع في الـ45% العلوية والباقي داكن فاضي للنص؛ نوفمبر: الموضوع يملأ الإطار).

## تحديث الأنماط كل شهر
كل نمط = فولدر في `app\styles\<id>\` فيه:
- `manifest.json` — الاسم والشهر والوصف و`renderer` و`image_style` (base / negative / compose لكل نوع صورة) و`fields`.
- `template\` — الـ CSS والخطوط واللوجو.
- وملف رندرر بايثون `renderer_<id>.py` في `app\` بدالة `build(sb, slot_files, workdir, chrome, log, outdir, draft)` وثابت `FRAME`.
النمط الأحدث (حسب `month`) هو الافتراضي في القايمة. نفس الـ storyboard يشتغل على أي نمط.


## نمط رؤية للصور — ثابت لكل الكاروسيلات (مصدر واحد)
الملف `app\image_style.json` هو المصدر الوحيد: **نمط ثابت (إيجابي) + برومبت سلبي ثابت** يتركّبوا لكل صورة، والمتغير الوحيد هو **موضوع الصورة** (Subject) اللي بيطلع من كلام الفيديو.
- التركيب لكل صورة: `[نمط رؤية الثابت] + [قاعدة تكوين النمط المختار] + [مقاس الإطار] + [الموضوع]`.
- لكل صورة تظهر في الصفحة: الموضوع، البرومبت الإيجابي، البرومبت السلبي، وأزرار نسخ (الإيجابي / السلبي / الاتنين).
- ملف `image_prompts.md` بيتكتب جوه فولدر كل كاروسيل بكل البرومبتات (رابط تنزيله في الصفحة).
- أنماط التصميم (Nov/Oct…) بتضيف قاعدة التكوين بس (`image_style.compose` في `manifest.json`) ولا تغيّر النمط الثابت.

## الـ storyboard
- بمفتاح `ANTHROPIC_API_KEY` (متغير بيئة) يتولد أوتوماتيك.
- بدونه: الكاروسيل يقف عند «في انتظار الـ storyboard»، وClaude يكتبه في `jobs\<id>\storyboard.json` من الشات (التعليمات في `storyboard_request.md`).

## مفاتيح وإعدادات
`app\config.json`: مسار ملف مفتاح ElevenLabs، لغة التفريغ، مسار Chrome، فولدر حفظ افتراضي.

## لسه مش مبني (للنسخة الأونلاين)
ربط درايف لكل مستخدم، Action على GitHub، تسجيل دخول. الخطة في `PLAN.md`.

## الفحص الذاتي (حماية من تكرار الأخطاء)
`app\selftest.py` بيشتغل تلقائيًا مع كل تشغيل (من `START.bat` ومن `server.py`)، من غير إنترنت وبدون أي استهلاك API. لو أي فحص فشل **السيرفر مش بيشتغل** ويطبع السبب.
بيفحص: الأدوات (ffmpeg/Chrome) · الملفات والقوالب · قراءة ملف سليم / صامت / تالف · بوابة جودة التفريغ · البنود الأساسية والتأصيل ضد الهلوسة · نمط برومبتات الصور · ثوابت الواجهة (زر «كمّل التصميم»، منع `confirm()`، المصطلحات الملغية، سلامة JavaScript).
**قاعدة العمل:** أي عطل جديد يتصلّح لازم يتضاف له فحص في `selftest.py` في نفس التعديل، وبعد كسر النظام عمدًا للتأكد إن الفحص بيفشل. تشغيل يدوي: `python selftest.py`. تجاوز طارئ فقط: `SET SKIP_SELFTEST=1`.


## تشغيل من الريبو (نسخة جديدة)
1. ثبّت Python 3.13 وffmpeg وGoogle Chrome وPillow.
2. انسخ `app/config.example.json` إلى `app/config.json` وعدّل مسارات ملفات المفاتيح (ElevenLabs / Gemini / Anthropic) — المفاتيح نفسها **ما بتتحطش في الريبو أبدًا**.
3. حط خطوط Graphik Arabic وArbFONTS (مرخّصة، مش مرفوعة هنا) في `app/styles/november/template/fonts/` و`app/styles/october/template/fonts/`.
4. شغّل `START.bat` وافتح http://localhost:8765
